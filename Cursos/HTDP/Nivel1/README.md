# Curso: How to Design Programs (HtDP) — Nivel 1: Datos de Tamaño Fijo

## 📘 Nivel 1: Datos de Tamaño Fijo (Fixed-Size Data)

### 🎯 ¿Qué aprenderás en este nivel?

Este nivel es la base fundamental para aprender a diseñar programas correctamente usando datos simples y de tamaño fijo. Aquí desarrollarás la mentalidad de un programador, aprendiendo a:

- **Identificar los tipos de datos** que intervienen en un problema (números, cadenas de texto, imágenes, booleanos).
- **Representar datos** de forma clara y precisa para manipularlos.
- **Diseñar funciones** que transformen esos datos siguiendo un proceso riguroso y comprobable.
- **Usar condicionales** para que tus programas puedan tomar decisiones y comportarse de forma diferente según el contexto.
- **Crear estructuras de datos simples** (como las posiciones `posn`) que te permiten organizar mejor la información.
- **Construir programas interactivos** que respondan a eventos y cambios, usando el modelo de mundos (`big-bang`).
- **Realizar pruebas automáticas** para verificar que tus programas funcionan correctamente.
- **Aplicar buenas prácticas** como el uso de constantes globales para que tu código sea más claro y fácil de mantener.

Este nivel combina teoría y práctica con ejemplos y ejercicios diseñados para que entiendas cada paso del diseño y aprendas a programar con confianza.

---

## 📚 Resumen de las secciones

### 1. Aritmética  
Explorarás operaciones básicas con diferentes tipos de datos: números, cadenas, imágenes y booleanos. Aprenderás a combinarlos y a entender cómo funcionan internamente.

### 2. Funciones y Programas  
Aprenderás a definir funciones desde lo más simple, entender su estructura y composición, y cómo integrarlas para construir programas pequeños pero funcionales.

### 3. Cómo Diseñar Programas  
Descubrirás un método paso a paso para diseñar funciones y programas de manera sistemática, incluyendo cómo escribir pruebas para garantizar la corrección.

### 4. Condicionales y Enumeraciones  
Aprenderás a usar condicionales para tomar decisiones en tus programas y a representar datos que pueden tomar un conjunto limitado de valores (enumeraciones e itemizaciones).

### 5. Añadiendo Estructura  
Comenzarás a trabajar con estructuras de datos (como `posn`) para representar datos más complejos y aprenderás a programar con ellas.

### 6. Itemizaciones y Estructuras Combinadas  
Avanzarás en el diseño combinando itemizaciones y estructuras, y aprenderás a manejar errores y validar estados en tus programas.

### 7. Resumen  
Revisarás y consolidarás todo lo aprendido para tener una visión completa y lista para avanzar a niveles superiores.
