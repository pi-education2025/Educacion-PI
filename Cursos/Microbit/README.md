# Curso Básico de micro:bit

## Descripción General

Este curso está diseñado para personas que desean iniciarse en la programación y electrónica a través del uso del micro:bit, una placa educativa fácil de usar y muy versátil. El curso abarca desde los conceptos básicos hasta proyectos prácticos que consolidan el aprendizaje.

## Objetivos del Curso

- Introducir a los estudiantes en la programación básica usando micro:bit.  
- Enseñar conceptos fundamentales de electrónica aplicada.  
- Fomentar el aprendizaje mediante proyectos prácticos y divertidos.  
- Desarrollar habilidades para resolver problemas y pensar de forma lógica.

## Requisitos

Para aprovechar este curso, necesitarás lo siguiente:  

- **Placa micro:bit.**  
- **Cable USB** para conectar el micro:bit al computador.  
- **Acceso a internet** para usar plataformas como MakeCode.  
- (Opcional) **Componentes electrónicos adicionales** como LEDs, botones, sensores, motores, etc., que permitirán ampliar la experiencia práctica.

## ¿Cómo usar MakeCode?

MakeCode es una plataforma en línea que permite programar el micro:bit de manera sencilla y visual. Estas son las formas principales de usar MakeCode:  

- **Editor en línea (recomendado):**  
  Puedes acceder directamente a [makecode.microbit.org](https://makecode.microbit.org) desde cualquier navegador, crear tus programas usando bloques visuales, JavaScript o Python, y descargar el archivo `.hex` para transferirlo al micro:bit.

- **Modo de bloques:**  
  Ideal para principiantes. Permite arrastrar y soltar bloques de instrucciones, facilitando el aprendizaje de la lógica de programación sin escribir código.

- **JavaScript:**  
  Para usuarios que desean ir más allá, MakeCode permite ver y editar el código en JavaScript, facilitando la transición a lenguajes de texto.

- **Python (beta):**  
  MakeCode también ofrece soporte para Python, un lenguaje de programación muy popular, aunque este curso se enfocará principalmente en bloques para facilitar el aprendizaje inicial.

- **Transferencia directa:**  
  Una vez creado el programa, se descarga un archivo `.hex` que se copia directamente al micro:bit conectado por USB, haciendo que el programa se ejecute inmediatamente.

## Estructura del Curso

El curso está dividido en tres niveles para facilitar un aprendizaje progresivo:

- **Nivel Básico**  
  En este nivel se aprenden los fundamentos del micro:bit, cómo conectar y programar el dispositivo con proyectos simples. Ideal para quienes nunca han programado antes.

- **Nivel Medio**  
  Se introducen sensores, variables, lógica condicional y bucles a través de proyectos interactivos más complejos que permiten fortalecer las habilidades adquiridas.

- **Nivel Avanzado (próximamente)**  
  Se abordarán conceptos más complejos, incluyendo comunicación inalámbrica, manejo de datos avanzados y proyectos integradores que fomenten la creatividad y el pensamiento crítico.
