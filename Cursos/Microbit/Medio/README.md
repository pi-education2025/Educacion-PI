# 🛠️ Nivel Medio - Micro:bit

## Descripción general

En este nivel, profundizaremos en el uso de sensores integrados en el micro:bit y la lógica condicional para crear programas más interactivos y útiles. Trabajaremos con el acelerómetro para detectar movimiento, el sensor de luz para responder a cambios en el ambiente, y usaremos números aleatorios para simular juegos.

Este nivel te ayudará a comprender cómo el micro:bit puede interactuar con el mundo físico y cómo podemos diseñar programas que reaccionen a estímulos reales.

---

## Contenido del Nivel Medio

### Sensores

- **Contador de Pasos**  
  Aprende a usar el acelerómetro para contar cada paso que das y mostrar el resultado en la pantalla LED.

- **Luz Nocturna**  
  Usa el sensor de luz para detectar cuando está oscuro y activar una luz en el micro:bit automáticamente.

### Lógica y Condicionales

- **Piedra, Papel o Tijera**  
  Crea un juego clásico que usa el acelerómetro para detectar un movimiento y genera un resultado aleatorio para piedra, papel o tijera.
