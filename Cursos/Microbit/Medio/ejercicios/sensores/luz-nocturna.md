# 🌙 Luz Nocturna

## Objetivo
Encender la pantalla LED automáticamente cuando hay poca luz.

## Conceptos clave
- Sensor de luz
- Condicionales (`si... entonces`)
- Mostrar imagen o limpiar pantalla

## Descripción
El programa revisa continuamente el nivel de luz y enciende una imagen si está oscuro.

## Bloques sugeridos
- por siempre
- si (nivel de luz < valor)
- mostrar icono o limpiar pantalla
