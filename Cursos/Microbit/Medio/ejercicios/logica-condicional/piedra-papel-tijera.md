# ✊✋✌ Piedra, Papel o Tijera

## Objetivo
Simular el juego clásico usando el micro:bit y el movimiento.

## Conceptos clave
- Sensor de movimiento (agitar)
- Números aleatorios
- Condicionales
- Mostrar íconos

## Descripción
Cuando se agita el micro:bit, se genera un número aleatorio que representa piedra, papel o tijera y se muestra el ícono correspondiente.

## Bloques sugeridos
- al agitar
- establecer número aleatorio (0 a 2)
- si... entonces... si no...
- mostrar icono
