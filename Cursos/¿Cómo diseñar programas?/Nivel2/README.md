# 🚀 Nivel 2 – Datos de Tamaño Arbitrario

En este nivel descubrirás cómo manejar datos que pueden crecer y cambiar de tamaño, como las **listas**. Aprenderás a diseñar datos que se definen a sí mismos (datos autorreferenciales) y a combinar funciones para crear programas más poderosos y flexibles.

Además, pondrás en práctica lo aprendido con proyectos prácticos que incluyen juegos y simuladores.

---

## 📚 Temas principales

- **Listas:** creación, manipulación y cálculos con ellas.  
- **Diseño autorreferencial:** cómo definir y usar datos que se refieren a sí mismos.  
- **Diseño por composición:** combinar funciones para construir soluciones complejas.  
- **Proyectos prácticos:** juegos, simuladores y aplicaciones reales.

---

## 📚 Descripción de cada sección

### Listas  
Aprenderás a crear y manipular listas, entender la lista vacía y cómo construir listas con `cons`. Trabajarás con funciones recursivas para procesar listas y realizar cálculos.

### Diseño con datos autorreferenciales  
Explorarás cómo definir datos que se refieren a sí mismos, incluyendo listas no vacías, números naturales y estructuras anidadas. Aplicarás estas ideas para modelar estados en programas.

### Más sobre listas  
Profundizarás en funciones que generan listas, listas que contienen estructuras o listas anidadas, y su uso en proyectos gráficos y manejo de archivos.

### Diseño por composición  
Aprenderás a combinar funciones de forma modular para construir programas más claros y reutilizables, usando funciones auxiliares recursivas y generalizadoras.

### Proyectos con listas  
Aplicarás todo lo aprendido en proyectos reales y divertidos, como juegos de palabras, simuladores y máquinas de estado, usando listas para manejar datos complejos.

### Resumen  
Repasarás y consolidarás los conceptos clave de todo el nivel para afianzar tu aprendizaje.
